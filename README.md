## What I've been working on

**[slice](https://github.com/jjk30/slice)** — AI & cloud cost gateway, live at [sliceapp.dev](https://sliceapp.dev). Routes prompts to cheaper models, caches repeats, and caps spend across Anthropic, OpenAI, Gemini, and NVIDIA NIM behind one API. 45% spend reduction on a 50-prompt workload, 92% routing accuracy from a locally served LoRA judge, 989 tests. FastAPI, Redis, Terraform on arm64 EC2, Prometheus/Grafana, 6-tool MCP server. `pip install slice-gateway`.

**[cpp-trading-exchange](https://github.com/jjk30/cpp-trading-exchange)** — Low-latency exchange in C++26: fixed-size memory pool, price-time order book with O(1) cancel, matching engine with self-trade prevention, lock-free MPSC queue, and a market data feed with sequence-gap detection. 113 GoogleTest cases, 96.6% line coverage on the matching engine. Built over an 8-week Build Fellowship mentored by a Citadel Securities engineer.

**[SneakersForLess](https://github.com/jjk30/sneakers-for-less)** — Sneaker price-comparison site with automated email price alerts, live at [sneakersforless.org](https://www.sneakersforless.org/). React frontend, Lambda + DynamoDB backend, SES for alerts, deployed on CloudFront with GitHub Actions CI/CD.

**[Old Is Gold](https://github.com/jjk30/old-is-gold)** — Fitness app for adults 55+, live at [oldisgold.fit](https://oldisgold.fit). Nutrition tracking, workout recommendations, and progress analytics on the same serverless stack, with sub-200ms response times.

**[bedrock-chatbot](https://github.com/jjk30/bedrock-chatbot)** — Multi-turn CLI chatbot on Amazon Bedrock using the Converse API with Amazon Nova Lite. Includes a second version wired to a Bedrock Guardrail that screens every turn's input and output.
